HTML zu SCORM

HTML-Code aus einem Vibe-Coding-Tool einfügen und als HTML-Datei oder als SCORM-Paket für Moodle (Aktivität „Lernpaket“) herunterladen. Alles läuft lokal im Browser, es wird nichts hochgeladen.

2 · Einstellungen

Keine zusätzlichen Dateien.
So kommt das Paket in Moodle
  1. Kurs öffnen → Bearbeiten einschalten → Aktivität oder Material anlegen → Lernpaket.
  2. Unter Paket die heruntergeladene .zip-Datei hochladen (nicht entpacken).
  3. Unter Bewertung z. B. „Höchste Bewertung“ wählen, wenn Punkte übertragen werden.
  4. Unter Aktivitätsabschluss „Status erforderlich: Abgeschlossen“ bzw. „Bestanden“ einstellen.
  5. Speichern und als Teilnehmer/in (Rolle wechseln) testen.
Punkte aus dem eigenen Code an Moodle melden

Im SCORM-Paket steht im HTML-Code automatisch ein Objekt SCORM zur Verfügung. Diese Zeilen kann man in den eigenen Code (oder in den Prompt fürs Vibe-Coding-Tool) aufnehmen:

// Ergebnis melden: erreichte Punkte, maximale Punkte
if (window.SCORM) SCORM.setScore(7, 10);

// Nur „abgeschlossen“ melden, ohne Punkte
if (window.SCORM) SCORM.complete();

Prompt-Baustein für das KI-Tool: „Wenn das Quiz beendet ist, rufe if (window.SCORM) SCORM.setScore(punkte, maxPunkte); auf. Alles in einer einzigen HTML-Datei.“

An Moodle wird der Prozentwert (0–100) übertragen – passend zur Standard-Höchstbewertung 100.

Außerhalb von Moodle (z. B. beim Öffnen der HTML-Datei) passiert dabei einfach nichts.
