Lernpfad-Baukasten

Lernpfade Schritt für Schritt mit KI erarbeiten. Sie füllen hier Felder aus und erhalten passende Prompts. Die Prompts geben Sie in AIS.chat oder ein anderes KI-System ein. Die Ergebnisse kopieren Sie zurück. Am Ende laden Sie den fertigen Lernpfad als SCORM-Paket (Moodle, LOGINEO.LMS) oder als HTML-Datei (TaskCards) herunter.

2 · Lernpfad planen

Kopieren Sie den Prompt in AIS.chat. Die KI plant den Lernpfad rückwärts vom Lernprodukt aus. Wenn Angaben fehlen, fragt sie nach. Fügen Sie die fertige Planung anschließend unten ein und übernehmen Sie die Stationen.

Prompt: Lernpfad planen

Danach in AIS.chat oder ein anderes KI-System einfügen.

Stationsübersicht

Sie können Stationen auch von Hand anlegen, umbenennen oder umsortieren.

3 · Feedback-Aufgabe für das formative Assessment

Legen Sie die Feedback-Aufgabe vor den Stationen an, damit der Link in den Lernpfad eingebaut werden kann. Der Prompt liefert alle Felder in genau der Form, die PEER bzw. FelloFish verlangt. Die Überarbeitung steuert das Feedback-Tool selbst.

Hinweis: Für FelloFish ist ein kostenpflichtiger Account erforderlich.

4 · Stationen erstellen

Für jede Station gibt es einen eigenen Prompt. Die KI erstellt daraus eine vollständige HTML-Datei. Fügen Sie den Code bei der Station ein. Navigation, Fortschrittsanzeige und Feedback-Button ergänzt der Baukasten automatisch.

Feedback-Links müssen in diesem Fall bereits im Code enthalten sein.

5 · Prüfen und herunterladen

Testen Sie den Lernpfad aus Sicht der Lernenden. Wenn eine Station nicht passt, bitten Sie die KI im selben Chat um Änderungen und fügen den neuen Code in Schritt 4 ein.

Herunterladen

Moodle / LOGINEO.LMS: Aktivität „Lernpaket“ anlegen und die .zip-Datei hochladen. Abgeschlossen gilt der Pfad, sobald die letzte Seite erreicht ist.
