AIS.chat Modelle

Welches Sprachmodell in AIS.chat passt zu Ihrer Aufgabe? Wählen Sie einen Einsatzzweck – vom Arbeitsblatt bis zum Vibe-Coding – und erhalten Sie eine begründete Rangfolge, die Qualität und Ihr monatliches Tokenbudget gegeneinander abwägt.

So arbeiten Sie mit dem Tool
  1. Einstellen: Unter „Meine Modelle“ abwählen, was in Ihrem Bundesland fehlt. Unter „Priorität“ festlegen, ob Qualität oder Budget wichtiger ist.
  2. Einsatzzweck: Aufgabe links wählen – rechts erscheinen Erste Wahl, Alternativen, ein Spartipp und Modelle, von denen abzuraten ist.
  3. Vergleichsmatrix: alle Modelle und Zwecke auf einen Blick.
  4. Steckbriefe: Fakten, Stärken, Schwächen und Budgetverbrauch je Modell.
  5. Vibe-Coding: Schritt-für-Schritt-Anleitung und Prompt-Vorlage für eigene Lern-Apps.

Die Einschätzungen beruhen auf Herstellerangaben, unabhängigen Benchmarks und den AIS.chat-Release-Notes (Details im Reiter „Methodik & Quellen“). Sie ersetzen nicht das eigene Ausprobieren.

Wie schnell ist das Budget weg?

AIS.chat rechnet das monatliche Tokenvolumen in Cent ab – nach den Token-Preisen des jeweiligen Modells (so steht es im offenen Quellcode). Vergleich für eine typische Anfrage mit rund 3.000 Token Eingabe und 1.500 Token Antwort, bezogen auf GPT-5 nano = 1. Reasoning-Modelle verbrauchen zusätzlich Denk-Token.

Grundlage: öffentliche Listenpreise der Anbieter. Was AIS.chat für das EU-Hosting tatsächlich zahlt, ist nicht veröffentlicht; die Verhältnisse dürften ähnlich sein. Llama-3.3-70B: Schätzung.

Vibe-Coding mit AIS.chat

Beim Vibe-Coding beschreiben Sie in Alltagssprache, was eine Anwendung können soll, und die KI schreibt den Code. Für Schule eignen sich einzelne HTML-Dateien: Sie laufen in jedem Browser, auch offline, und brauchen keinen Server.

Wichtig: AIS.chat zeigt Code als Codeblock mit Kopieren- und Download-Schaltfläche, hat aber keine Live-Vorschau. Sie speichern die Datei und öffnen sie im Browser.
  1. Idee schärfen

    Was soll die App tun, wer nutzt sie, auf welchem Gerät? Drei bis fünf konkrete Funktionen reichen für den ersten Entwurf.

  2. Modell für den Entwurf wählen

    Claude Sonnet 5.5 liefert die zuverlässigsten vollständigen Dateien. Fehlt es in Ihrem Land: GPT-5.5 oder Claude Sonnet 4.6.

    Sonnet 5.5GPT-5.5Sonnet 4.6
  3. Code übernehmen

    Codeblock herunterladen oder kopieren, in einem Texteditor als lernapp.html (UTF-8) speichern und per Doppelklick im Browser öffnen.

  4. Testen und Fehler genau beschreiben

    Was haben Sie geklickt, was ist passiert, was war erwartet? Fehlermeldungen aus der Browser-Konsole (Taste F12) mitschicken.

  5. Budgetbewusst nachbessern

    Für kleine Änderungen wie Texte, Farben oder Schriftgrößen reicht Gemini 3.5 Flash Lite oder GPT-5.6-luna. Bei hartnäckigen Fehlern das Modell wechseln, etwa GPT-5.5 als Zweitmeinung. Lange Chats werden teuer, weil der ganze Verlauf mitgeschickt wird: nach einigen Runden einen neuen Chat beginnen und die aktuelle Datei einfügen.

    3.5 Flash LiteGPT-5.6-luna
  6. Prüfen und teilen

    Fachlich gegenprüfen, keine personenbezogenen Daten erfassen lassen. Teilen über die Lernplattform (z. B. Moodle) oder eine eigene Webseite.

Prompt-Vorlage für den Erstentwurf

Ausgefüllt mit einem Beispiel – Thema und Funktionen ersetzen.

Erstelle eine interaktive Lernanwendung als EINE vollständige HTML-Datei: HTML, CSS und JavaScript in einer Datei, ohne externe Bibliotheken, lauffähig offline im Browser.

Thema: Brüche mit gleichem Nenner addieren
Zielgruppe: Klasse 6, Mathematik
Funktionen:
- zufällige Aufgaben mit Nennern von 2 bis 12
- Eingabe des Ergebnisses, sofortige Rückmeldung mit kurzer Erklärung
- Brüche zusätzlich als Kreisdiagramm darstellen
- Zähler für richtige Antworten, Schaltfläche „Neue Aufgabe“
Gestaltung: deutschsprachig, große Schaltflächen, gut lesbar auf Tablet und Beamer, hoher Kontrast.

Gib den vollständigen Code in einem einzigen Codeblock aus. Erkläre danach in drei Sätzen, wie ich die Datei teste.

Prompt-Vorlage für Fehlerberichte

Die Datei funktioniert noch nicht wie gewünscht.
Was ich getan habe: Ich habe auf „Neue Aufgabe“ geklickt.
Was passiert: Das Kreisdiagramm bleibt leer.
Was erwartet war: Beide Brüche erscheinen als Kreisausschnitte.
Fehlermeldung aus der Konsole (F12): Uncaught TypeError: ctx is null

Finde die Ursache, erkläre sie in einem Satz und gib die vollständige korrigierte Datei aus.

Im Unterricht: Lernende coden selbst

Die Prüfungswerkstatt beschreibt mit dem „Simulations- und Vibe-Coding-Assistenten“ (Uni Siegen, Idee 4.11) ein Format, in dem Lernende mit KI eine Simulation erstellen, sie systematisch testen, Grenzen benennen und das Produkt mündlich verteidigen. Für solche Lernszenarien ist GPT-5.6-luna ein guter Kompromiss: brauchbarer Code zu einem Bruchteil der Kosten von Sonnet 5.5.

So entstehen die Einschätzungen

Qualität (0–5) je Einsatzzweck: Herstellerbenchmarks und unabhängige Messungen (Artificial Analysis, Vals.ai, SWE-Bench, Terminal-Bench, Langkontext-Test AA-LCR) sowie bekannte Eigenschaften wie Bildverarbeitung, Kontextlänge und Reasoning – übersetzt in eine redaktionelle Einschätzung für Schulaufgaben.

Rangfolge: Qualität plus gewichteter Budgetvorteil. „Beste Qualität“ gewichtet das Budget kaum, „Budget schonen“ stark. Modelle unter 2,5 Punkten landen immer unter „Nicht empfohlen“.

Budget: Laut AIS.chat-FAQ erhält jede Lehrkraft ein monatliches Tokenvolumen, das am Monatsersten auf 100 % zurückgesetzt wird; geteilte Lernszenarien und Dialogpartner verbrauchen einen von Ihnen festgelegten Anteil davon.

Grenzen: Welche Modelle verfügbar sind, entscheidet jedes Bundesland. Benchmarks stammen teils von den Herstellern. Modelle in AIS.chat können anders konfiguriert sein (z. B. Denkaufwand) als in den Tests. Ergebnisse immer prüfen.
